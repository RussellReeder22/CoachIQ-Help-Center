You choose a product's type when you select **+ Create** on **Payments → Products**. The type decides how the family pays and which settings the [Product Builder](/payments/product-builder) shows.

| | One-Time | Subscription | Access Code |
| --- | --- | --- | --- |
| **Payment** | Once, at checkout | Every billing period | Redeems a code, no card payment |
| **Can be free** | Yes, price \$0.00 | Yes, price \$0.00 | Yes, with a code |
| **Credits** | Optional, added once | Optional, added every period | Optional, added on redemption |
| **Free trial or later first charge** | No | Yes | No |
| **Use for** | Drop-ins, packages, camps | Memberships, monthly plans | Sponsored, scholarship, partner, staff access |

## One-Time

The family pays once at checkout. Nothing renews.

Use it for:

- A single drop-in session or evaluation
- A credit package, such as 10 sessions with credits that expire after 90 days
- A camp, clinic, or event registration
- Lifetime access to a program

**Examples**

- "60-Minute Private Lesson" for \$75, no credits. Used as the payment on a paid scheduler.
- "10-Session Package" for \$650 with 10 credits that expire 90 days after purchase.
- "Summer Camp Week 1" for \$250 with a total purchase limit of 24.

## Subscription

The family's card or bank account is charged on a schedule, such as every month, until the subscription reaches its set end or is canceled.

Use it for:

- Monthly memberships
- Credit plans, such as 4 credits a month
- Ongoing program access
- A season billed in installments, using an end date or a set number of payments

Subscription-only settings include billing frequency, an initial down payment, a set end, a free trial, and **Schedule charges for later**. See [Product Builder: Payment](/payments/product-builder#payment).

**Examples**

- "4 Sessions a Month" for \$280 a month, 4 credits each month, unused credits expire at renewal.
- "Unlimited Membership" for \$200 a month with **Unlimited Credits** (shown to families as **∞**).
- "Fall Season" for \$150 a month, ending after 4 payments.

To change or cancel a family's subscription, see [Managing subscriptions](/payments/manage-subscriptions).

## Access Code

The family enters a code you gave them and gets the product without paying by card. Each code can have its own usage limit.

Use it for:

- Sponsored or scholarship athletes
- Partner organizations or teams you've agreed to cover
- Staff or assistant coaches who need access

**Example**

"Scholarship Access" with the code `SCHOLAR2026` limited to 10 uses, adding 8 credits on redemption.

On your website, a code-only product shows **Code** instead of a price. At checkout, the family types the code into the **Access code** field. An invalid code shows a message beside the field and doesn't create a booking or order.

<Note>
  **Access code or coupon?** An access code unlocks the product without a card payment. A [coupon](/payments/coupon-overview) lowers the price of a paid product. Use a coupon for a discount such as 50% off.
</Note>

### Allow a code on a paid product

A One-Time or Subscription product can also accept codes. Turn on **Enable access codes** in the product's **Payment** section and add codes. Families can then pay the price or enter a code. Code holders skip payment; everyone else pays.

## Choosing a type

1. **Will the family pay again automatically?** Yes: **Subscription**. No: keep going.
2. **Should only people you choose get it free?** Yes: **Access Code**, or a paid product with **Enable access codes** if others should be able to buy it.
3. Otherwise: **One-Time**.

## Changing the type later

The type is set when you create the product. To switch, create a new product with the right type, place it where the old one was, and archive the old one. Existing purchases and subscriptions stay on the old product.

## Several products for one service

One service can have several products. For example, a private-lesson scheduler can take a \$75 drop-in product at checkout, while families with a 10-session package or a monthly membership pay with credits. See [Use products in schedulers, programs, and forms](/payments/attach-products).
