Open **Scheduling → Schedulers → Create scheduler**. This guide follows one service from setup to a booking link families can use.

Before starting, decide what you offer, which lengths families can choose, how many athletes can attend together, and how they pay. If you charge by card, [connect Stripe](/payments/connecting-stripe) and create the necessary [products](/payments/product-builder).

## 1. Name the service

In **Details**, enter a **Title** and **Description**. Use a name such as “Private Hitting Lesson” and explain who it is for, what happens, and what to bring. Avoid putting one length in the title if you offer several lengths.

Choose a **Catalog** type such as **Lessons**, **Camps & events**, or **Rentals**. Tags help staff find it later; they are separate from the client tags used for access.

<Frame>
  ![Scheduler builder with Details, Catalog, and Team visibility](/images/create-scheduler-button.png)
</Frame>

## 2. Choose lengths and capacity

Open **Advanced settings**:

- Choose the duration or **Session lengths** families can book.
- Check **New sessions can start**. This sets the spacing between offered start times, not the length of a session.
- Set **Max athletes per time slot** to the number who can attend together. Use 1 for a private lesson.
- Add buffers if you need time before or after sessions.

<Frame>
  ![Advanced settings with multiple session lengths selected](/images/scheduler-session-lengths-2026-09.png)
</Frame>

For example, a 60-minute lesson can offer starts every 30 minutes without allowing overlapping bookings. See [start times and overlap](/scheduling/overlapping-slots) before enabling overlap.

## 3. Connect availability

In **Availability**, select the template containing this service's days and hours. Create one first under **Scheduling → Setup → Availability** if needed.

<Frame>
  ![Availability section with the connected template](/images/scheduling-review-oct01/connected-availability-verified.jpg)
</Frame>

Set start and end dates if this offering runs for a limited period. **Additional Availability** adds another template or seasonal block. Review both blocks' date ranges so they do not open unintended times.

Availability templates can be shared. Editing one affects the available times of other schedulers using it. See [Create availability](/scheduling/create-your-availability) and [seasonal transitions](/scheduling/seasonal-schedule-transition).

## 4. Choose how families pay

Open **Payment**:

| Choice | Configure |
| --- | --- |
| **Free** | No payment or credits required |
| **Paywalled → Price** | Select the product purchased to book |
| **Paywalled → Credit** | Set the credit cost and optional Buy more credits link |
| **Paywalled → Either** | Configure both the product and credit cost |

<Frame>
  ![Scheduler payment controls for price and credits](/images/scheduling-review-oct01/payment-price-verified.jpg)
</Frame>

If you offer several lengths, use **Price by session length** to override each length's product or credit cost. Otherwise it inherits the default. See [length pricing](/scheduling/pricing-by-session-length).

For credits, also check the issuing product's **Which schedulers accept these credits** setting. The scheduler's credit cost does not grant permission to use every product's credits.

## 5. Add the people and space

Set the **Location** families should attend. Use a saved Google Meet or Zoom location for online sessions.

In **Coaches**, select the staff who run the service and review conflict settings. In **Resources**, attach the cages, courts, or rooms the session reserves. A location address alone does not prevent two sessions using the same space.

- [Coach setup and conflicts](/scheduling/managing-availability-for-multiple-coaches)
- [Locations and per-date venues](/scheduling/setup-locations)
- [Resources and reservation behavior](/scheduling/resources)

## 6. Review booking rules and reminders

Before sharing, review **Advanced settings** for minimum booking notice, how far ahead families can book, cancellation notice, credit refunds, and rescheduling permissions. Set limits only where you need them; session-wide limits and per-athlete limits have different effects.

Use **Team visibility** if only athletes with selected roster tags should book. Leave it unrestricted for your group's general offering. Configure **Reminders** for this scheduler.

- [Booking rules and limits](/scheduling/scheduler-settings-limits-and-permissions)
- [Visibility and tags](/scheduling/organizing-schedulers#team-visibility)
- [Session reminders](/scheduling/session-reminders)

## 7. Preview and save

Review the builder's **Preview** on an intended date. Change the selected length and confirm the available times. A capped slot shows its booked count against capacity; an unlimited slot shows the booked count without a one-person maximum.

Choose **Create** for a new scheduler or **Update** when editing. Confirm **Active** is on when you are ready to accept bookings.

If no times appear, follow [booking troubleshooting](/scheduling/troubleshooting) rather than widening your hours without checking the cause.

## 8. Publish and verify

Copy the scheduler's link from its card. To display it in the athlete app, add it to **Athlete Portal → Edit → Schedule**, then choose **Update Page**. Website placement is configured separately. Follow [Share and publish schedulers](/scheduling/sharing-schedulers).

Check the actual booking page:

1. The intended athlete can see the service; restricted athletes cannot book it.
2. Each offered length has the correct dates, times, and payment or credit requirement.
3. The location and selected athlete are correct on the review screen.
4. A controlled free or credit test appears in the calendar under the attending athlete, with the expected credit entry and confirmation.
5. The booking page remains usable on a phone.

You can inspect paid checkout without submitting a purchase. Test cards work only in a confirmed Stripe test environment; completing live checkout makes a real payment.

For later changes, see [Changing your schedule](/scheduling/changing-your-schedule).
