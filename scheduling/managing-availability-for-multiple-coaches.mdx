For a team of coaches, start by deciding **who must be available for each service**. Then connect those coaches, set their hours, and check how simultaneous sessions should behave.

## Set up your team

1. [Connect your coaches](/scheduling/setup-coaches) and set their working availability.
2. [Create availability](/scheduling/create-your-availability) for each service's bookable hours.
3. Open each scheduler's **Coaches** section and select the appropriate coaches.
4. Attach any required [resources](/scheduling/resources), such as a court or batting cage.
5. Review the calendar and customer booking times for overlapping services.

Coach hours, service availability, bookings, resources, and booking rules all contribute to the times an athlete can book.

## Specific coaches versus All

Use specific assignments when a particular coach is responsible for a service. If two services require the same coach, a booking on one can block the overlapping time on the other.

A scheduler set to **All** has its own conflict behavior. Review the setting described as **Check this box if this session needs every coach**:

| All-coaches setting | Conflict behavior |
| --- | --- |
| Needs every coach | Can conflict with sessions assigned to specific coaches as well as other All-coaches sessions |
| Does not need every coach | All-coaches sessions conflict with other All-coaches sessions, without treating every named coach as required |

An older scheduler may use the automatic setting until you explicitly choose its behavior. Review it when adding staff or diagnosing an unexpected blocked time.

This setting controls conflicts. It does not create extra seats, assign an instructor by rotation, or multiply a session's capacity by the number of coaches.

## Allow simultaneous services intentionally

For example, Coach Maya can lead private hitting while Coach Jordan runs a pitching clinic at the same time if their staffing, resources, availability, and booking rules permit it.

If both services need the same cage, connect that resource to both. Different coaches do not make one physical resource available twice.

The connected-coaches overlap option allows bookings even when connected coaches are already scheduled elsewhere. Use it only when the coach can actually cover the overlap. It is different from [offering overlapping start times](/scheduling/overlapping-slots) or allowing several athletes into one group session.

## Coach-specific services

Use separate schedulers when the services have different coaching assignments, availability, or pricing—for example, **Hitting with Maya** and **Pitching with Jordan**. A single service can still offer several [session lengths and prices](/scheduling/pricing-by-session-length).

Do not assume selecting multiple coaches automatically assigns one available coach to each new booking. Review the configured coach options and the saved booking's actual staffing.

## Verify the setup

Check a representative time for each service and compare it with a time where a coach or resource already has a booking. Confirm:

- Available times match the coach's working hours and service schedule.
- An existing commitment blocks the services it should.
- Independent coaches and resources can run simultaneous sessions as intended.
- The session's participant limit matches your group size.

If a time is still missing, use [Scheduling troubleshooting](/scheduling/troubleshooting) before turning on an overlap override.
